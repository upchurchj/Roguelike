⚔️ KnightLight Roguelike

A procedurally-generated dungeon crawler for Android — built entirely in Java, on-device, using Termux.

📖 View Source Code 🔗 GitHub Repo

Game Features

🏰 Procedural Generation

Each playthrough generates a unique dungeon layout with randomized rooms, corridors, enemy placements, and loot distribution.

⚔️ Turn-Based Combat

Tactical combat system with action points, strategic positioning, equipment bonuses, and enemy AI behaviors.

📦 Equipment System

Loot collection with rarity tiers (Common, Rare, Epic, Legendary), stat modifiers, and inventory management.

💾 Save & Load

Persistent save system allowing players to resume their adventure across multiple sessions.

📈 Progression

Experience system with leveling, skill advancement, and increasingly challenging dungeon depths.

📱 Mobile-First Design

Optimized for Android touch interface with responsive layouts supporting phones and tablets.

Development Tech Stack

Built on Android device using open-source tooling

Java Android SDK Gradle 8.6 Termux Git F-Droid

About This Project

Developed by John Upchurch as a demonstration of Android development capabilities using minimal infrastructure. This project showcases proficiency with procedural algorithms, game architecture patterns, and mobile development constraints.
